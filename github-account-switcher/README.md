# GitHub Account Switcher — переключатель аккаунтов для Firefox

Расширение для Firefox (работает и на компьютере, и на телефоне): войдите под
каждым аккаунтом GitHub один раз, нажмите «Сохранить текущий» — и дальше любой
аккаунт переключается в один тап.

**Важно:** расширение не хранит и не видит пароли. Оно сохраняет только
сессионные куки GitHub (то, что браузер и так держит после входа). Это
единственный надёжный способ мгновенно переключать аккаунты — программный вход
с паролем GitHub блокирует (капча, 2FA, WebAuthn).

## Как пользоваться

1. Откройте `github.com` и войдите под первым аккаунтом.
2. Нажмите иконку расширения → **＋ Сохранить текущий**.
3. Выйдите / зайдите под вторым аккаунтом и снова нажмите **＋ Сохранить текущий**.
4. Дальше один тап по аккаунту в попапе — все открытые вкладки GitHub
   перезагрузятся и покажут выбранный аккаунт. Если вкладок GitHub нет —
   откроется `github.com`.

В попапе можно переименовать аккаунт (кнопка ✎) и удалить (✕, с подтверждением).

### Если GitHub «выкинул» из аккаунта

Сессии GitHub со временем истекают (смена пароля, безопасность, ~долгий
перерыв). Тогда просто войдите заново и нажмите «Сохранить текущий» — старый
снимок сессии заменится новым.

## Установка

### Компьютер — быстро (для проверки)

1. В Firefox откройте `about:debugging#/runtime/this-firefox`.
2. «Загрузить временное дополнение…» → выберите файл `manifest.json` из этой
   папки.
3. Иконка появится на панели. Минус: временное дополнение исчезает после
   перезапуска Firefox.

### Постоянная установка (компьютер и телефон)

Firefox разрешает ставить только подписанные Mozilla дополнения, поэтому один
раз нужно получить подпись (бесплатно, ~5 минут):

1. Соберите архив:
   ```bash
   cd github-account-switcher
   ./build.sh                       # → github-account-switcher.xpi
   ```
2. (Рекомендуется) Замените `id` в `manifest.json` на свой, например
   `"github-account-switcher@ваш-домен.example`, и пересоберите.
3. Зайдите на https://addons.mozilla.org/developers/ (аккаунт Mozilla, бесплатно)
   → «Отправить новое дополнение» → выберите `github-account-switcher.xpi` →
   на шаге распространения выберите **«Распространять самостоятельно»**
   (расширение нигде не публикуется). Через несколько минут получите
   **подписанный** `.xpi` для скачивания.
4. **Компьютер:** сохраните файл, затем в Firefox: Меню → «Дополнения и темы»
   → шестерёнка → **«Установить дополнение из файла»** → выберите файл → «Добавить».
5. **Телефон (Firefox for Android):** перекиньте подписанный `.xpi` на телефон
   (Google Drive, скачивание по ссылке и т.п.):
   - В Firefox: Настройки → О Firefox.
   - Тапните логотип Firefox **пять раз подряд** (откроются скрытые пункты).
   - Настройки → **«Установить расширение из файла»** → выберите файл →
     «Добавить».
   - Иконка расширения появится в меню ⋯. Попап удобно открывать прямо с
     панели/меню — тап по аккаунту переключит все вкладки GitHub.

Дальше обновления ставятся так же (собрали → подписали → переустановили).

## Как это устроено

- **`background.js`** — вся работа: снять слепок кук, очистить куки GitHub,
  восстановить куки другого аккаунта, перезагрузить вкладки `*.github.com`.
- **`lib/hub-lib.mjs`** — чистая логика (фильтрация/сериализация кук, профили),
  без API браузера; покрыта тестами (`tests/account-switcher-lib.test.ts`).
- **`popup/`** — интерфейс: список аккаунтов, кнопки сохранить/переименовать/
  удалить. Свёрстан под телефон (крупные кнопки, тап-зоны ≥ 44 px).

Профили (только куки) хранятся в `browser.storage.local` самого расширения.

## Ограничения и безопасность

- Куки — это чужие сессии для GitHub: переключение не «логин», а подмена
  сессии. Единственный механизм — как у всех рабочих свитчеров аккаунтов.
- Если включены **контейнеры Firefox**: расширение сохраняет аккаунт из того
  контейнера, в котором вы были, и переключает аккаунты в нём же. На Android
  контейнеров нет — всё работает в обычных вкладках.
- Не используйте расширение на чужих/шаред устройствах: тот, у кого есть доступ
  к Firefox, сможет переключиться на сохранённые сессии. Лучше удалять профили
  при передаче устройства.
- При подозрительной активности GitHub может потребовать повторный вход —
  это защита самого GitHub, обойти её нельзя (и не нужно).

## Разработка

```bash
cd github-account-switcher
./build.sh        # собрать .xpi
```

Проверка линтером (`npx web-ext lint` из этой папки), тесты — из корня репозитория:
`npm test` (или только `npx vitest run tests/account-switcher-lib.test.ts`).
